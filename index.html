Projects

Dynamic Parallelized Ray Tracing for High-Performance Rendering

  • Developed a distributed ray tracing engine featuring an Adaptive Load Balancing algorithm to improve rendering performance in complex 3D scenes.
  • Implemented a dynamic feedback loop that tracks rendering times per image block and automatically adjusts block boundaries, distributing smaller workloads to heavily loaded compute nodes.
  • Evaluated the engine across 4, 8, and 16 distributed nodes, achieving up to a 26% reduction in aggregate rendering time over multiple frames by leveraging temporal coherence.
  • Analyzed parallel performance bottlenecks, identifying communication overhead and serial synchronization limits at higher node counts to inform future hybrid scaling strategies.

RISC-V ISA based Superscalar, Out-of-Order Processor

  • Designed, simulated and synthesized a 2-way Superscalar, Out-of-Order RISC-V processor in SystemVerilog with 8 functional units, 256 Byte I-cache, and 256 Byte D-cache.
  • Integrated several advanced features, including a PAg Branch Predictor, Dual-Ported I-cache, Write-Back D-cache, Store Queue and Instruction Prefetching.
  • Conducted thorough unit testing and system debugging, achieving a synthesizable design with an average CPI of 2.61 and strictly compliant with RISC-V ISA standards across over 40 assorted Assembly and C test programs.
